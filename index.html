Alur Kerja — 4 Step Wizard
🔑
Login

Pilih divisi (Asset / FOP / NetDev) → masukkan token → klik Masuk. Divisi dan kode Collect ID otomatis terisi sesuai akun.

1
Step 1 — Detail Tagging

Pilih Jenis Kegiatan → isi Date & Division → PIC Full Name → Foto PIC & Tanda Tangan → Foto Site & Rack.

2
Step 2 — Functional Location

Site Name/ID/Type → Subregion, City, Floor → Functional Location, Plant, Work Center, Cost Center otomatis terisi → Capture Location (GPS) → alamat lengkap & Region/Country otomatis ter-ekstrak.

3
Step 3 — Equipment

Tambah Asset (Device Tunggal / Modul) → pilih dari katalog → Object Type (SAP) otomatis terisi → lengkapi S/N, P/N, foto, dan status device.

4
Step 4 — Send & Generate

Kirim Email (ZIP otomatis ter-download) atau Generate PDF / Excel (3-sheet format SAP) / Label QR. Progress bar & Collect ID selalu terlihat di atas selama proses.

🧭 Navigasi Wizard
Klik lingkaran step di progress bar untuk pindah ke step yang sudah pernah dikunjungi. Tombol Lanjut / Kembali di bawah tidak diblok validasi — kamu bisa lihat-lihat semua step dulu. Validasi lengkap baru dicek saat menekan tombol Kirim Email / Generate di Step 4; kalau ada yang belum lengkap, klik pesan errornya untuk langsung diarahkan ke step yang bermasalah.
Checklist Sebelum Kirim
✅ Step 1: Foto PIC & Tanda Tangan PIC sudah diisi, minimal 1 foto Site & Rack
✅ Step 2: Functional Location, Plant/Work Center/Cost Center, dan Koordinat GPS sudah terisi
✅ Step 2: Detail alamat (Street, RT/RW, Kelurahan, Kecamatan, Region, Country) sudah lengkap — cek manual kalau GPS tidak dapat semua data
✅ Step 3: Semua device sudah punya foto, S/N, P/N, dan Object Type (SAP) terisi
✅ Step 3: Status device sudah dipilih (Active / Damage / Spare)
✅ Tidak ada S/N duplikat antar device maupun sub-modul
✅ Step 4: File ZIP sudah ter-download dan di-attach ke email

Jenis Kegiatan
🆕
New Site

Instalasi aset di site baru yang belum pernah tercatat. Semua field site dan device wajib diisi lengkap.

📌
Existing

Pendataan ulang aset di site lama. Digunakan saat site sudah ada tapi data perlu diperbarui.

➕
Additional

Penambahan device baru ke site yang sudah ada sebelumnya.

🗑️
Dismantle

Pelepasan/pembongkaran aset dari site. Wajib isi alasan dismantle dan lokasi penyimpanan (warehouse).

🔄
Replace

Penggantian device lama dengan device baru. Isi data device lama (dilepas) dan device baru (dipasang).

🏷️
Re-Tagging

Label fisik device rusak atau hilang. Isi kondisi label lama, sumber temuan, dan alasan. Generate label baru setelah selesai.

ℹ️ Collect ID
Otomatis terbuat setelah pilih kegiatan dan isi Site ID. Format: NEW-4091-KYB032-AM-20260422-C480
Terdiri dari: Kode Kegiatan · Subregion · Site ID · Divisi · Tanggal · Kode Unik. Tidak dapat diubah manual. Banner Collect ID ini selalu tampil di bawah progress bar, di semua step.

Pemulihan Data Otomatis
1
Auto-Save Aktif

Setiap perubahan form langsung tersimpan otomatis ke penyimpanan lokal browser.

2
Foto Tersimpan di IndexedDB

Foto PIC, TTD, foto site, dan foto device tersimpan terpisah — tetap ada meski halaman di-refresh.

3
Pulih Otomatis

Buka kembali halaman setelah tutup/refresh → semua data dan foto langsung dipulihkan. Toast "Foto draft dipulihkan" akan muncul.

⚠️ Jangan hapus cache browser
Foto disimpan di IndexedDB browser. Menggunakan fitur "Clear Site Data" atau "Hapus Data Situs" akan menghapus semua foto yang belum ter-ZIP secara permanen. Selalu download ZIP terlebih dahulu sebelum membersihkan cache browser.
Masalah Umum & Solusi
📍 GPS tidak akurat atau tidak muncul
Pastikan Location Permission diizinkan di browser. Coba di luar ruangan atau gunakan mode Input Manual / Klik Peta.
🎤 Mikrofon tidak merespons
Aktifkan izin mikrofon di pengaturan browser. Pastikan tidak ada aplikasi lain yang menggunakan mikrofon. Gunakan Chrome atau Edge.
📷 Kamera scanner / kamera foto tidak terbuka
Aktifkan izin kamera di browser. Gunakan Chrome versi terbaru. Pastikan halaman dibuka via HTTPS, bukan file://.
🏷️ Collect ID tidak berubah setelah ganti user
Logout lalu login ulang dengan akun yang benar. Collect ID otomatis diperbarui saat login berhasil — tidak perlu refresh manual.
📊 Scanner barcode terbuka tapi tidak terbaca
Coba tab "Upload Foto" di modal scanner — foto barcode dari galeri lebih reliable untuk barcode kecil atau DataMatrix. Pastikan foto hanya area barcode, tidak full device, dan tidak buram.
🖼️ Foto tidak muncul setelah refresh
Jangan hapus data browser/cache. Foto disimpan di IndexedDB. Jika sudah terhapus, foto tidak bisa dipulihkan — selalu download ZIP dulu sebelum clear cache.
📦 File ZIP tidak bisa di-download
Izinkan pop-up dan download otomatis di browser. Di mobile, buka menggunakan Chrome. Pastikan storage device tidak penuh.
🔑 Token salah / tidak bisa login
Hubungi Admin untuk mendapatkan token yang benar. Token bersifat case-sensitive. Jangan ada spasi di awal/akhir.
⚠️ Muncul peringatan S/N duplikat dan tidak bisa kirim
Pengecekan S/N sekarang mencakup device utama dan sub-modul. Tidak ada opsi "Tetap Kirim" — wajib perbaiki S/N yang duplikat terlebih dahulu. Klik "Kembali & Perbaiki" untuk melihat device mana yang bermasalah.
🏷️ QR Code label di-scan tapi form tidak terisi
Pastikan activity sudah dipilih dulu sebelum scan QR label — aplikasi hanya bisa menambah device setelah jenis kegiatan ditentukan. Scan ulang setelah pilih activity.
